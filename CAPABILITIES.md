# القدرات / Capabilities

## ماهي قدراتك؟ / What are my capabilities?

### العربية

أنا وكيل برمجي متقدم مدعوم من GitHub Copilot، ولدي مجموعة واسعة من القدرات في مجال تطوير البرمجيات:

#### قدرات البرمجة
- **لغات البرمجة المتعددة**: أجيد العديد من لغات البرمجة بما في ذلك Python، JavaScript، TypeScript، Java، C#، Go، Rust، Ruby، PHP، وغيرها
- **تطوير الويب**: إنشاء وتعديل تطبيقات الويب باستخدام أطر عمل مختلفة (React، Vue، Angular، Django، Flask، Express، وغيرها)
- **تطوير واجهات برمجة التطبيقات**: تصميم وتنفيذ واجهات RESTful وGraphQL APIs
- **قواعد البيانات**: العمل مع SQL وNoSQL (PostgreSQL، MySQL، MongoDB، Redis، وغيرها)

#### إدارة المشاريع
- **إدارة الإصدارات**: استخدام Git لإدارة التغييرات والفروع والدمج
- **التكامل والنشر المستمر**: إعداد وصيانة CI/CD pipelines
- **إدارة التبعيات**: استخدام npm، pip، Maven، وغيرها من أدوات إدارة الحزم

#### الاختبار والجودة
- **كتابة الاختبارات**: إنشاء اختبارات الوحدة والتكامل والشاملة
- **فحص الكود**: استخدام أدوات Linting ومدققات الأكواد
- **مراجعة الكود**: تحليل التغييرات وتقديم ملاحظات بناءة
- **الأمان**: فحص الثغرات الأمنية باستخدام CodeQL والأدوات الأخرى

#### التوثيق
- **كتابة الوثائق**: إنشاء وتحديث الوثائق الفنية وملفات README
- **التعليقات البرمجية**: إضافة تعليقات واضحة ومفيدة للكود
- **دلائل الاستخدام**: كتابة أدلة المستخدم والمطور

#### قدرات إضافية
- **التشخيص وإصلاح الأخطاء**: تحليل وحل مشاكل الكود
- **التحسين والأداء**: تحسين أداء التطبيقات وكفاءتها
- **الهندسة المعمارية**: تصميم بنية البرمجيات وأنماط التصميم
- **أتمتة المهام**: إنشاء نصوص برمجية لأتمتة المهام المتكررة
